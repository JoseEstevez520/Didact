# Didact — Visual Language

This is Didact's default look: a **neutral, low-chroma, high-contrast** system that looks finished
without imposing a brand. It is implemented as tokens in `@didact/theme` and consumed by every
component through those tokens (see [`design-principles.md`](./design-principles.md) §1). The
values below are Didact's defaults; any consumer overrides them.

## Palette

Near-monochrome by design. The default theme is built from neutral greys with a near-black
foreground and a near-white background; there is no saturated brand accent baked in. Semantic
roles (each available in a light `:root` scale and a `.dark` scale):

- `background` / `foreground` — page surface and primary text.
- `card` / `card-foreground`, `popover` / `popover-foreground` — raised surfaces.
- `primary` / `primary-foreground` — the strongest neutral emphasis (a dark surface with light
  text), used sparingly.
- `secondary` / `secondary-foreground`, `muted` / `muted-foreground`, `accent` /
  `accent-foreground` — quiet fills and secondary text.
- `border`, `input` — hairline separators and field outlines (a light grey, kept subtle).
- `ring` — the focus indicator color (a mid grey).
- `destructive` — the single reserved status color, for genuinely destructive actions.

There are no green/orange "status" colors in the default theme by design. When a component needs to
signal correct/incorrect or success/warning, it must do so with **text and/or an icon** — never
color as the only signal (WCAG 1.4.1). A consumer that wants dedicated status tokens can add them.

## Shape and scale

- **Radius:** a single base radius of `0.625rem`, with a derived `sm / md / lg / xl` scale
  (`calc()` off the base). Controls and chips use the small/medium radius; surfaces (cards,
  popovers) use the larger base radius.
- **Restraint:** components are compact and quiet. Small text with medium weight, tight padding,
  hairline borders, no heavy shadows or gradients. The interface should recede so the learning
  content stands out.
- **Badges/chips:** gently rounded (`rounded-md`), `text-xs` / medium weight, minimal padding,
  transparent border by default — a small, calm status marker, not a loud button.

## Focus

Focus is always visible and never removed without a substitute (WCAG 2.4.7). The default is a
**3px ring in the `ring` color at ~50% opacity**, plus a ring-colored border — soft but
unmistakable, and consistent across every interactive component.

## Typography

Sans-serif by default, with relative (never fixed-`px`) sizes so users can scale text. Long-form
text is line-length limited (~60–70 characters) and never justified, for readability including
dyslexic readers.

## Motion

Motion is subtle and centralized through a duration token. Every animation respects
`prefers-reduced-motion` (WCAG 2.3.3): when reduced motion is requested, durations collapse to
zero. Motion is never required to understand state.

## Contrast — status

**Audited** (real OKLCH→sRGB conversion + WCAG 2.1 relative-luminance math, not just the formula's
theoretical values) in `packages/validators/a11y/contrast-audit.{json,md}`, generated by
`packages/validators/a11y/scripts/contrast-audit.mjs`. The theme uses the reference design system's
exact default token values, so its contrast characteristics are those of that proven system.
Result, both light and dark:

- **All text pairs pass WCAG 1.4.3 (≥ 4.5:1)**: `foreground`/`background` (~19:1),
  `primary-foreground`/`primary` (~14–17:1), `secondary-foreground`/`secondary` (~14–16:1), and
  `muted-foreground`/`background`. The tightest is `muted-foreground` on `background` in **light**
  mode at **4.73:1** — over the bar, but the smallest margin, so re-run the audit if that token
  changes.
- **Non-text pairs (WCAG 1.4.11, ≥ 3:1) — a known trade-off inherited from the reference default,
  honestly reported and NOT silently patched:** the focus **`ring`** passes in dark (4.18:1) but is
  **2.59:1 in light mode**, below the 3:1 bar; and **`border`** is intentionally a decorative
  hairline (~1.25:1). This is exactly how the reference's default theme behaves. Author rule: never
  rely on `border` alone to convey a boundary or state. If strict WCAG 1.4.11 for the focus
  indicator is required for a given deployment, darkening the light-mode `ring` token is a one-line,
  conscious divergence from the reference default (re-run the audit afterward).

Re-run `node packages/validators/a11y/scripts/contrast-audit.mjs` any time a token's OKLCH value
changes.
